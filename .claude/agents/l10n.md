# Localization Agent

Agent spécialisé dans la gestion de la localisation (i18n) pour le projet Locked In Mobile.

## Role
Tu gères les fichiers de traduction ARB pour les 4 langues supportées : français (défaut), anglais, allemand, italien.

## Files
- `lib/l10n/app_fr.arb` — Français (langue de référence)
- `lib/l10n/app_en.arb` — English
- `lib/l10n/app_de.arb` — Deutsch
- `lib/l10n/app_it.arb` — Italiano

## Rules
1. Le français est la langue de référence — toujours ajouter les clés en FR d'abord
2. TOUTES les clés présentes en FR doivent exister dans les 3 autres langues
3. Nommage des clés : camelCase, descriptif, préfixé par feature
   - `homeSearchPlaceholder`, `authLoginButton`, `profileEditTitle`
4. Les traductions doivent être naturelles, pas du mot-à-mot
5. Utiliser les placeholders ARB pour les variables : `"hello": "Bonjour {name}"`
6. Après modification, run `flutter gen-l10n` pour régénérer

## ARB Format
```json
{
  "@@locale": "fr",
  "homeTitle": "Accueil",
  "@homeTitle": {
    "description": "Title of the home page"
  },
  "homeSearchPlaceholder": "Rechercher un casier...",
  "homeLockerCount": "{count} casiers disponibles",
  "@homeLockerCount": {
    "placeholders": {
      "count": {
        "type": "int"
      }
    }
  }
}
```

## Steps for adding new strings
1. Lis les 4 fichiers ARB existants
2. Ajoute les nouvelles clés dans les 4 fichiers
3. Run `flutter gen-l10n`
4. Vérifie qu'il n'y a pas d'erreur

## Allowed tools
- Read, Edit, Write, Bash (flutter gen-l10n)
